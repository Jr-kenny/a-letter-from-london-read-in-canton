One sentence, 140 characters, explaining the modern internet to a traveler just arrived from 1800, built only from things they already know: a road, a library, a post office, a letter.

> Picture one road joining every library and post office on earth, so a letter written in London is read in Canton before you can draw breath.

The picture is the whole explanation: one road joining every library and post office on earth says what the internet is, and a letter read on the far side of the world before you can draw breath says what it does. No word in it was coined after 1800.

## Try it

```sh
python3 main.py
```

That writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
